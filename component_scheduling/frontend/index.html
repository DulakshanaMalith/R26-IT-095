How does Auto-Balance Workload work? Click to expand
1
LPT Sort — Longest Processing Time First
Individual tasks are sorted by effort hours in descending order. Assigning the heaviest task first (when all members have equal load) ensures no one ends up with all the big tasks.
2
Random Forest ML — P_on_time Scoring
For each task, the Random Forest model scores every member using 7 features (effort, complexity, completion rate, current workload, avg effort, category, collaborative flag). The member with the highest P_on_time probability (chance of finishing on time) is selected.
3
Overload Guard — Fairness Constraint (40% Threshold)
If the RF-selected member already has 40% more hours than the least-loaded member (W_best > W_min × 1.40), the system overrides the ML decision and assigns to the least-loaded member instead. This mathematically prevents overloading.
